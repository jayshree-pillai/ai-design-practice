import asyncio

async def run_batch(questions,service):
	semphore = asyncio.Semaphore(3)
	results ={}
	async def process_one(question):
		async with semaphore:
			try:
				answer = await service.answer(question)
				results[question["id"]]={
					"answer":answer,
					"success":True,
					"error":None}
			except ex:
				...
	tasks =  [process_one(q) for q in questions]
	await asyncio.gather(*tasks)
	return results

FunctionApp>>HostProcess>>Python Worker Process actually running invoke
	Azure routes the request to a host instance.
	The Functions host dispatches the invocation to a Python worker.
	That worker executes its chat() handler.
	The handler calls await graph.ainvoke(...) on its compiled graph.
	The workflow completes and the handler returns the answer.
	Different requests can be handled by different workers. Each invocation has separate execution state.
